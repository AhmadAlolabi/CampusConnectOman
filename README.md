# CampusConnectOman

A Java client-server application developed as an individual Advanced Programming assignment.

## Overview

CampusConnectOman allows a client to submit a student ID, select a service, and choose a priority type. The server retrieves student and service information from a database, calculates the service bill, and returns the results to the client.

## Technologies Used

* Java
* Java Sockets
* Client-server communication
* JDBC
* Apache Derby
* SQL
* Multithreading fundamentals

## Key Features

* Sends student and service details from the client to the server.
* Retrieves student and service information from a database.
* Calculates service fees and applicable adjustments.
* Returns billing details and expected delivery time to the client.

## Project Structure

* `CampusConnectOmanClientMain.java` — Client application.
* `CampusConnectOmanServerMain.java` — Server application.
* `Utilitytask.java` — Supporting utility code.

## Skills Demonstrated

* Java programming
* Socket communication
* Database connectivity using JDBC
* SQL queries
* Input validation
* Basic client-server architecture
